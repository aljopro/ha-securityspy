- (decision) AD-1 paradigm: two-plane data flow — lossy push plane (event stream) for latency-sensitive state, authoritative poll plane (caplist/status) for persistent truth; every persistent value must be derivable from the poll plane alone. Prevents stream-accumulated state that dies on restart (briis failure mode).
- (decision) AD-2 library split: all SecuritySpy protocol knowledge (framing, endpoints, field/bitmask decoding, bool read/write asymmetry, anonymizer, episode reduction) lives in aiosecurityspy on PyPI; integration contains zero protocol parsing. ADOPTED from PRD FR-40.
- (decision) AD-3 detection-episode reducer lives in the library as a pure configurable component (threshold/debounce injected); integration supplies config from options flow. Prevents integration re-implementing signal semantics and keeps reducer testable without HA.
- (decision) AD-4 coordinator: single DataUpdateCoordinator per config entry, no update_interval; fed via async_set_updated_data from stream callbacks and from polls the integration schedules. No hand-rolled data hub (unifiprotect pattern is legacy).
- (decision) AD-5 identity: hub identifiers (DOMAIN, server_uuid); camera (DOMAIN, f'{server_uuid}_{camera_number}'); never name/host/MAC; no connections tuples; via_device to hub; hub entry_type SERVICE; has_entity_name=True everywhere. ADOPTED from PRD FR-21 + research §8. Permanent.
- (decision) AD-6 error taxonomy: library raises typed exceptions (AuthError, ConnectError, PermissionError, UnsupportedVersionError); integration maps once in __init__/config_flow to ConfigEntryAuthFailed (after 3 consecutive auth failures) / ConfigEntryNotReady / ConfigEntryError with translation keys. No HA imports in library.
- (decision) AD-7 arming writes use override only, never schedule assignment; schedules read-only via dynamic select. ADOPTED from PRD FR-13.
- (decision) AD-8 settings-backed controls write partial POSTs directly on state change (verified safe); no read-modify-write cache. Library encodes JSON-bool-read vs 1/0-write asymmetry once.
- (decision) AD-9 Object Class is open string data end-to-end; no enum anywhere; built-in classes are constants, not a closed type. ADOPTED from PRD FR-34.
- (decision) AD-10 polling: one batched caplist request per cycle (cams=all, server-side class filter per class = 3 requests/cycle max, not 3xN); event-driven poll trigger on FILE stream events plus slow fallback interval. Lookback window default 7 days [ASSUMPTION].
- (decision) AD-11 stream lifecycle (CR framing, 10s heartbeat watch, backoff reconnect, reconnect-reconcile signal) owned by the library client; integration subscribes to callbacks and triggers reconciliation on the library's reconnected signal.
- (decision) AD-12 runtime data via typed ConfigEntry alias + entry.runtime_data; never hass.data[DOMAIN]. PARALLEL_UPDATES=0 in every platform module.
- (decision) AD-13 credential safety: anonymizer lives in library and is the only path to diagnostics output; settings payloads never logged at any level; stream URLs constructed with credentials only inside the library.
- (decision) AD-14 repo topology: two public GitHub repos — aiosecurityspy (library, PyPI trusted-publisher CI) and ha-securityspy (integration, HACS custom repo). [ASSUMPTION: two repos rather than monorepo — HACS requires exactly one integration per repo and Bronze dependency-transparency wants independent library CI].
